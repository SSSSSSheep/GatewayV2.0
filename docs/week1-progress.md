| 用例 | 输入 | 期望 |
|---|---|---|
| 正常地址 | `"0002"` | 输出 `00 02`，长度 2 |
| 正常控制字节 | `"31"` | 输出 `31`，长度 1 |
| 大小写混合 | `"aF"` | 输出 `AF` |
| 空输入 | 长度为 0 | 成功，输出长度 0 |
| 奇数长度 | `"123"` | 非法文本错误 |
| 非法字符 | `"3G"` | 非法文本错误 |
| 空间不足 | `"0002"`，容量 1 | 空间不足错误 |
| 空输入指针 | NULL，长度非零 | 参数错误 |
| 空输出指针 | 非空输入，输出 NULL | 参数错误 |
| 空长度指针 | `out_len == NULL` | 参数错误 |
| 中途非法字符 | `"313G"` | 失败，输出缓冲区不被部分修改 |
| 显式长度输入 | 没有 NUL 结尾的字符数组 | 按给定长度正确转换 |
